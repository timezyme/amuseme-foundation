# AmuseMe foundation

This is the separately supplied foundation for [AmuseMe's Meta hackathon submission](https://github.com/timezyme/meta-hackathon-paper-tours). It is a mixed-origin integration frozen on October 28, 2026, containing earlier document-processing code and event-era adaptations. It is **not a pre-event revision**, and none of its contents are claimed as new submitted work.

[Download the frozen source archive](https://github.com/timezyme/amuseme-foundation/releases/download/foundation-2026-10-28/foundation.zip). The event repository contains the later changes, reconstruction tool and run instructions. The archive has no credentials, private application data, installed dependency directories or Git history. Vendored prototype libraries and fonts retain their notices.
